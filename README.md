# Problem Solving Agent Skill v0.1

版本：`v0.1`，首个公开版本。仓库：`agent-problem-solving-skill`。这是行为规则初版，尚未证明相对基线的效果提升。

一条通用主线“明确交付并验收”，三个按需方法“证据核验、假设驱动排障、方案权衡”。最小试验是共享动作；系统因果图仅辅助跨组件反复故障。关键判断是：未知的不同答案是否会改变交付、行动或风险。

## 文件入口

- `skills/problem-solving/SKILL.md`：实际安装单元与行为入口。
- `skills/problem-solving/references/`：三份按需加载的方法参考。
- `evals/test-cases.md`：可复现输入、场景材料和评测者预期。
- `evals/evaluation-criteria.md`：评分及同条件对照流程。
- `docs/design-review.md`：报告对照、协作原则核对边界。
- `docs/validation.md`：实际检查、未运行验证和剩余缺口。
- `docs/publication.md`：GitHub 发布前的具体步骤。

## 安装与调用

将 `skills/problem-solving` 整个文件夹复制到目标客户端配置的 skills 目录，保持文件夹名 `problem-solving` 及内部结构。不要复制整个仓库作为一个 Skill，不要改动全局 AGENTS.md。不同客户端的发现目录和刷新方式以其实际配置为准；安装后先确认列表中可见，再在新会话试用。若同名 Skill 已存在，先比较并备份，避免覆盖。

在支持显式调用的客户端中示例：`使用 $problem-solving，检查重试后重复通知的问题并修复。` 支持自动选择的环境可根据入口描述发现它；本包不关闭自动选择，但发现和触发是否成功仍需在实际客户端验证。普通聊天中粘贴说明不等于安装。

示例：

- “从已给公告摘录截止日期”：直接回答，不额外查资料或问技术问题。
- “修复重试后的重复通知”：观察输入到展示的路径，区分原因，修复并复测。
- “评估是否需要重构”：先看现有系统与真实改动，再比较有实质差异的路线。

用户保留目标、偏好、优先级、预算和授权决定；AI 承担技术研究、选择、实施和验证。Skill 不扩大现有授权。

## 测试情况与评测方法

按 `evals/evaluation-criteria.md` 在隔离环境做基线与 Skill 配对运行，输入使用 `evals/test-cases.md` 的用户请求与材料，预期结果仅供评测者使用。记录真实产物、工具调用和验收证据，不能靠阅读规则推断有效性。

当前完成静态结构与内容审查；没有实际模型对照成绩或真实项目效果结论。已按六条全局协作原则完成内容核对。详见验证记录。

## 发布与许可

仓库名称与公开可见性已由用户确认。未选择开源许可证；公开可见不自动授予开源使用许可。此版本不附加未经选择的许可证。安装与修改全局配置不是发布的一部分。

## 获取指定版本

从本仓库 Releases 下载 `v0.1` 源码包并解压，安装单元为 `skills/problem-solving`。也可克隆仓库后切换到 `v0.1` 标签；只阅读和评测时无需安装。卸载时移除自己复制的 Skill 文件夹，保留其他配置。
